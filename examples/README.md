# 示例:三种结论长什么样

```bash
python examples/make_examples.py     # 重新生成 old.json / new.json(确定性,随时可复现)
lev compare examples/old.json examples/new.json --label-a v1 --label-b v2
```

两份文件是**同一套 60 道题**上、改动前后的两个版本。三个指标被刻意设计成
三种不同的结论 —— 这正是这个工具存在的意义:它们**不能**被印成同一句话。

## 三个指标,三种结论

| 指标 | v1 → v2 | 分歧对 | 精确 p | Holm 校正后 | 结论 |
|---|---|---|---|---|---|
| 求解 / 给出答案 | 70.0% → 90.0% | 16 | **0.0042** | 0.0125 | **显著改善** |
| top-1 方法族命中 | 83.3% → 91.7% | 5 | 0.0625 | 0.1250 | **证据不足** |
| top-1 卡片命中 | 66.7% → 66.7% | 0 | 1.0000 | 1.0000 | **逐题相同** |

### 1. 显著改善 —— 值得合并

+20 个百分点,95% 配对 Bootstrap 区间 `[+6.7%, +30.0%]` **不跨 0**,
McNemar 精确 p = 0.0042。三个指标一起做 Holm 校正后是 0.0125,仍然显著。

注意 **Holm 校正确实抬高了门槛**:裸看是 0.0042,报 3 个指标就得按 3 倍要求
(校正后 0.0125)。一次报 6 个指标、每个都用 α=0.05 的话,"至少一个假阳性"的
概率接近 `1 − 0.95⁶ ≈ 26%` —— 校正不是学术洁癖,是别自己骗自己。

### 2. 证据不足 —— 不是"没变好",是"没测出来"

+8.3 个百分点看着不小,95% 区间 `[+1.7%, +15.0%]` 也不跨 0 —— 但 **p = 0.0625**,
落在 0.05 上面一点点。

**原因是分歧对只有 5 道。** 60 道题的规模下,净改善至少要 **6 道**才可能显著。
这个例子就卡在门槛下面一道。

报告会顺便告诉你下一步要多少样本:

```
按当前观测到的分歧率,要 80% 功效检出这个差异约需 92 道配对题(现在只有 60 道)。
—— 但这只是量级参考:分歧率本身是从这么小的样本估出来的。
```

**这才是"不显著"该有的样子**:不是一个死结论,而是一句可执行的话。

### 3. 逐题相同 —— 这是"没有差异",和上面那条完全不同

两版在每一道题上结果都一样,分歧对 **0**。

这时候:

* 精确 p = 1.0000;
* 报告写的是 **「逐题相同」**,不是「证据不足」;
* 也不给"要多少样本"的建议 —— 因为**扩样本没有任何用**。

把这条和第 2 条印成同一句"不显著",读者会去扩样本、白花标注预算。
这是整个工具最想强调的一个区分。

## 一条反直觉的推论

McNemar 精确检验**以分歧对的数量为条件**,所以:

> 单纯扩大评估集并不会提高判别力。

第 2 条那个指标,如果把 60 题扩到 200 题、而新增的 140 道两版表现都一样,
**检出能力一点都不会提高**。要提高判别力,只能针对性地补那些"两版确实会
分歧"的题。`lev plan` 就是用来算这笔账的:

```bash
lev plan --delta 0.05 --baseline 0.7
```
